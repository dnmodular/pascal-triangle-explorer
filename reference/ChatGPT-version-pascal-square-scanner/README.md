# Pascal · Square Scanner — standalone reconstruction

This ZIP is a **new, self-contained reconstruction**, not a download of the original site's source repository. The published preview did not expose its source files to inspection.

## Run it
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. No build tools, package installs, or internet connection are required.

## Included
- Pascal-triangle residue visualization using exact integer coefficients (`BigInt`)
- Row count, modulus, fractional offset, and cell scale controls
- Color palettes, cell outlines, and glow
- Basic animated directional/pulse modes
- Presets and SVG export

## Not included
The original project's full feature set—such as its Grassmannian/plane atlas, determinant-based motion, and Lava surface renderer—is not reproduced here. Those features would need to be rebuilt from specifications or the original editable source.
